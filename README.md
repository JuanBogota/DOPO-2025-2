# DOPO – Desarrollo Orientado por Objetos

Repositorio académico correspondiente a la asignatura **Desarrollo Orientado por Objetos (DOPO)**, donde se recopilan los trabajos, talleres, laboratorios y proyectos desarrollados durante el semestre **2025-2**.

- **Universidad:** Escuela Colombiana de Ingeniería Julio Garavito  
- **Programa:** Ingeniería de Sistemas  
- **Asignatura:** DOPO – Desarrollo Orientado por Objetos  
- **Semestre:** 2025-2  

---

## 🎯 Propósito del repositorio

Este repositorio tiene como objetivo centralizar y organizar todo el material desarrollado en la asignatura **DOPO**, incluyendo:

- Talleres
- Laboratorios
- Parciales
- Proyectos
- Diagramas UML
- Documentación de apoyo

Sirve tanto como evidencia académica del curso como referencia para el estudio de los principios de la **programación orientada a objetos**.

---

## 🧠 Contenidos principales

A lo largo del curso se trabajan conceptos como:

- Encapsulamiento
- Herencia
- Polimorfismo
- Abstracción
- Diseño orientado a objetos
- Modelado con UML
- Buenas prácticas de programación
- Organización y versionamiento de proyectos con Git
